🔀 Rule Scope Priority Cascade (First Matching Rule Wins)
When evaluating payroll rules for an employee, the system follows this strict priority hierarchy:
1
Employee-Specific Rule Override (Highest Priority — Custom Employee Contract overrides all)
2
Position / Designation Exception (Second Priority — Role specific exceptions e.g. System Administrator)
3
Department Base Baseline (Third Priority — Department baseline scale e.g. Engineering ₹95,000)
4
Company Default Rules (Default Fallback — Universal organization defaults)
